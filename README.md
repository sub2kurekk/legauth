
# Legauth

Do you want to relive the simpler Minecraft times, specifically the times before Microsoft Accounts killed the old Mojang accounts?

# Well... Now you can!

This project is a custom Auth Server compatible with Yggdrasil. You can use with ANY launcher you want (the only condition is that it needs to support authlib-injector login). We recommend Fjord Launcher (a Prism Launcher fork).

## Installation

You need npm and node.js!
```bash
  1. npm i - Install dependiences
  2. cp .env.example .env - Copy and rename the file to .env
  3. (sudo) nano .env - Customize preferences
  4. npm start - Start the server (finally lol)!
```
